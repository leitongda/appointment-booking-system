## MODIFIED Requirements

### Requirement: 构建任务必须以实例和模板为单位执行
系统 SHALL 以“小程序实例 + 模板版本”的组合发起构建任务，并记录模板版本和生成来源。

#### Scenario: 发起带模板上下文的实例构建任务
- **WHEN** 管理员选择某个小程序实例并触发构建
- **THEN** 系统创建构建任务
- **AND** 记录所用模板代码、模板版本、实例标识、构建参数和触发人

#### Scenario: 不同模板生成不同产物体验
- **WHEN** 两个实例复用相同业务内核但使用不同模板
- **THEN** 系统生成各自独立的前端产物
- **AND** 构建记录中可追踪模板来源

### Requirement: 发布配置必须保留模板生成来源
系统 SHALL 在上传、提审、发布和回滚流程中保留模板来源信息，支持后续模板回归和版本审计。

#### Scenario: 查看发布任务来源
- **WHEN** 管理员查看某次发布任务详情
- **THEN** 系统显示对应实例、模板代码、模板版本和构建产物信息
- **AND** 管理员可据此判断该版本来自哪套模板
