## MODIFIED Requirements

### Requirement: 模板与小程序实例分离建模
系统 SHALL 将模板定义与租户的小程序实例分离建模，并要求小程序实例能够绑定一个明确的前端风格模板。

#### Scenario: 租户基于模板创建小程序实例
- **WHEN** 平台管理员或租户管理员创建小程序实例
- **AND** 选择一个模板、模板版本、实例名称、微信 `appid` 和默认门店
- **THEN** 系统创建一个新的小程序实例
- **AND** 该实例关联所选模板版本
- **AND** 该实例记录模板代码与实例配置

#### Scenario: 同一业务内核生成不同风格实例
- **WHEN** 两个实例绑定相同业务能力但不同模板
- **THEN** 系统为两个实例生成不同的前端壳层体验
- **AND** 两个实例仍复用同一套业务接口和核心流程
