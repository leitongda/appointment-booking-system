# 低代码页面编辑器 — 用户指南

## 1. 快速入门

### 进入编辑器

1. 登录管理后台
2. 左侧菜单选择 **平台管理 > 页面管理**
3. 页面列表中可查看所有已创建的低代码页面（草稿、已发布、已归档）
4. 点击右上角 **新建页面** 按钮进入空白编辑器

### 编辑器布局

编辑器采用三栏布局：

| 区域 | 位置 | 功能 |
|------|------|------|
| 物料面板 | 左侧 | 所有可用组件，按分类展示，支持搜索 |
| 画布区 | 中间 | 实时预览和操作组件 |
| 属性面板 | 右侧 | 配置选中组件的各项属性 |

顶部工具栏提供撤销、重做、预览、保存、发布等操作。

---

## 2. 创建页面

1. 点击 **新建页面**，进入空白画布
2. 从左侧物料面板拖拽组件到画布（详见第 3 节）
3. 点击画布中的组件，右侧面板显示其属性
4. 修改属性值，画布实时更新（详见第 4 节）
5. 首次保存时，系统弹窗要求填写：
   - **页面名称**（必填）：如"科室介绍"、"预约须知"
   - **页面标识 (slug)**：自动生成拼音标识，可手动修改
6. 保存后，编辑器地址栏自动切换为该页面的编辑 URL

---

## 3. 添加组件

### 拖拽操作

在左侧面板中找到需要的组件，按住鼠标左键拖动到画布中的目标位置，松开即可添加。

### 组件分类

编辑器提供四大类组件：

**基础组件**
| 组件 | 说明 |
|------|------|
| 文本 (NutText) | 富文本展示，支持字号、颜色、字重、对齐 |
| 图片 (NutImage) | 图片展示，支持上传，可配置尺寸和填充模式 |
| 按钮 (NutButton) | 操作按钮，支持主要/默认/警告/危险类型 |
| 分割线 (NutDivider) | 内容分隔线，支持虚线样式 |

**布局组件**
| 组件 | 说明 |
|------|------|
| 布局容器 (NutView) | 通用容器，设置内边距、外边距、背景色、圆角 |
| 栅格行 (NutRow) | 水平排列容器，支持间距和对齐方式 |
| 栅格列 (NutCol) | 24 栏栅格的列，设置列宽占比 |

**展示组件**
| 组件 | 说明 |
|------|------|
| 轮播 (NutSwiper) | 图片轮播，支持自动播放、循环、指示器 |
| 轮播项 (NutSwiperItem) | 轮播中的单张图片（放入轮播容器内） |
| 单元格 (NutCell) | 列表项，带标题和描述 |
| 卡片 (NutCard) | 卡片容器，带标题和描述 |
| 标签页 (NutTabs) | 选项卡容器 |
| 标签面板 (NutTabPane) | 选项卡中的面板（放入标签页容器内） |
| 空状态 (NutEmpty) | 空数据占位提示 |

**表单组件**
| 组件 | 说明 |
|------|------|
| 输入框 (NutInput) | 单行文本输入，支持标签、占位符、必填校验 |
| 多行输入 (NutTextarea) | 多行文本输入，支持自适应高度 |
| 开关 (NutSwitch) | 开关切换控件 |
| 选择器 (NutPicker) | 下拉选择，支持弹窗式选择 |
| 表单容器 (NutForm) | 表单容器，统一配置标签位置和宽度 |

### 搜索组件

在左侧面板顶部的搜索框中输入组件名称，可快速过滤。

---

## 4. 配置属性

### 操作步骤

1. 在画布中点击要配置的组件（选中后有蓝色边框标识）
2. 右侧属性面板自动显示该组件的可配置属性
3. 修改属性值，画布实时反映变化

### 属性控件类型

| 控件 | 说明 | 示例 |
|------|------|------|
| 输入框 | 文本输入 | 页面标题、占位文字 |
| 文本域 | 多行文本 | 组件描述、长文本内容 |
| 数字输入 | 数值调节 | 间距、列宽、播放间隔 |
| 下拉选择 | 枚举选项 | 字重、对齐方式、按钮类型 |
| 颜色选择 | 色值选取 | 文字颜色、背景色 |
| 开关 | 布尔切换 | 是否禁用、是否显示 |
| 图片上传 | 图片资源 | 图片地址、背景图 |

### 删除组件

选中组件后，属性面板顶部显示 **删除** 链接，点击即可移除该组件及其所有子组件。

---

## 5. 预览与发布

### 预览

- 点击顶部工具栏的 **预览** 按钮，在新标签页打开预览页面
- 预览页面模拟小程序真实渲染效果
- 仅已保存的页面可预览

### 发布

1. 确认页面内容无误后，点击顶部 **发布** 按钮
2. 系统会自动先保存当前内容，再执行发布
3. 发布成功后，页面状态从"草稿"变为"已发布"

### 页面状态

| 状态 | 说明 |
|------|------|
| 草稿 | 未发布，可编辑和删除 |
| 已发布 | 对外可见，可继续编辑并重新发布 |
| 已归档 | 不再对外展示 |

### 从列表操作

在页面管理列表中，还可对草稿状态的页面直接执行：
- **复制** — 创建副本，自动打开编辑器
- **发布** — 无需进入编辑器直接发布
- **删除** — 删除草稿页面（需确认）

## 6. 快捷键与技巧

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+Z / Cmd+Z | 撤销 |
| Ctrl+Shift+Z / Cmd+Shift+Z | 重做 |
| Ctrl+S / Cmd+S | 保存 |

### 实用技巧

**布局搭建顺序**：先用布局容器和栅格搭建页面骨架，再往容器内填充内容组件。

**组件嵌套**：轮播项 (NutSwiperItem) 需放入轮播 (NutSwiper) 内；标签面板 (NutTabPane) 需放入标签页 (NutTabs) 内；表单组件建议放入表单容器 (NutForm) 内。

**未保存保护**：编辑器自动检测未保存的更改。关闭浏览器、切换页面或点击返回时，会弹窗提示保存。

**页面复制**：创建新页面时，可在列表中找到类似页面，点击"复制"快速生成副本，再在副本上修改。

**拖拽排序**：画布中的组件支持拖拽调整顺序和层级。

## 常见问题

**Q: 画布为空白，无法操作？**
确认已从左侧面板拖入组件。空白画布表示页面没有内容。

**Q: 修改属性后画布没有变化？**
检查是否选中了正确的组件（蓝色边框标识），以及属性值格式是否正确（如颜色需为 #hex 格式）。

**Q: 预览页面显示空白？**
确认页面已保存。如果仍有问题，尝试刷新编辑器后重新保存。

**Q: 发布后页面内容未更新？**
发布操作会自动保存当前内容。如果列表中状态未更新，刷新列表即可。
