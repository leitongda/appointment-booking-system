# Analytics Domain

> Data statistics and user behavior analysis

- Base Path: /api/v1
- Authentication: Bearer Token (JWT)

This domain contains 2 modules with 16 endpoints.

---

## 数据统计

- [GET /api/v1/statistics/overview](/api/v1/statistics/overview): 获取概览数据
- [GET /api/v1/statistics/appointments/trend](/api/v1/statistics/appointments/trend): 获取预约趋势
- [GET /api/v1/statistics/appointments/status](/api/v1/statistics/appointments/status): 获取预约状态统计
- [GET /api/v1/statistics/departments/ranking](/api/v1/statistics/departments/ranking): 获取科室预约排行
- [GET /api/v1/statistics/doctors/ranking](/api/v1/statistics/doctors/ranking): 获取医生预约排行
- [GET /api/v1/statistics/time-slots/distribution](/api/v1/statistics/time-slots/distribution): 获取时段分布统计
- [GET /api/v1/statistics/weekday/distribution](/api/v1/statistics/weekday/distribution): 获取星期分布统计
- [GET /api/v1/statistics/revenue/trend](/api/v1/statistics/revenue/trend): 获取收入趋势
- [GET /api/v1/statistics/appointments/summary](/api/v1/statistics/appointments/summary): 获取预约汇总统计
- [GET /api/v1/statistics/stores/ranking](/api/v1/statistics/stores/ranking): 获取门店预约排行
- [GET /api/v1/statistics/store-dashboard](/api/v1/statistics/store-dashboard): 获取门店专属Dashboard统计

## 用户行为分析

- [POST /api/v1/analytics/track](/api/v1/analytics/track): 上报埋点
- [POST /api/v1/analytics/batch](/api/v1/analytics/batch): 批量上报
- [GET /api/v1/analytics/logs](/api/v1/analytics/logs): 获取日志列表
- [GET /api/v1/analytics/overview](/api/v1/analytics/overview): 获取概览统计
- [GET /api/v1/analytics/tenant-activity](/api/v1/analytics/tenant-activity): 租户活跃度统计
