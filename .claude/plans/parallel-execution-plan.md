# 并行执行方案 — 医院预约挂号系统改进

## 执行策略

将 19 项任务划分为 **6 条并行轨道（Track）**，按依赖关系编排，最大化并发。

---

## 依赖分析

```
1.1 Token 黑名单 ──── 1.3 Refresh 轮换
                   └─ 4.3 生产加固
1.4 密码修改 ────── 4.3 生产加固
2.1 Prometheus ──── 2.3 健康仪表盘
                └── 2.4 Grafana

其余任务完全独立，可任意并行。
```

---

## 关键路径分析

**最长路径：** Track A (16h) + Track D (24h) = **40h 纯执行时间**

**但实际可用并行度：**

| 时间窗口 | 并行执行的任务 | 工时 |
|----------|---------------|------|
| 0-12h | Track A + B + C 同时进行 | 39h 工作量压缩到 12h 窗口 |
| 12h+ | Track D + E + F 同时进行 | 35h 工作量压缩到 ~24h 窗口 |

**实际总耗时：约 36-40 小时**（从 76-96h 串行压缩到 40h 并行）

## 并行执行分组（按 Agent 分配）

### 第一波（立即启动，3 个 Agent 并行）

**Agent 1 — Track A（认证安全链）**
```
A1 → A2 → A3
1.1 Token 黑名单 → 1.3 Refresh 轮换 → 1.4 强制改密
```

**Agent 2 — Track B（安全基础设施）**
```
B1 → B2 → B3 → B4
1.2 安全头 → 1.5 限流默认 → 1.7 Dockerfile → 1.6 CI 扫描
```

**Agent 3 — Track C（CI/CD + 代码质量）**
```
C1 → C2 → C3 → C4 → C5
3.3 Dependabot → 3.2 部署触发 → 4.1 Ruff → 4.2 Hook清理 → 4.4 依赖锁定
```

### 第二波（第一波完成后启动，3 个 Agent 并行）

**Agent 4 — Track D1-D3（可观测性核心）**
```
D1 → D2 → D3
2.1 Prometheus → 2.2 结构化日志 → 2.5 Sentry
```

**Agent 5 — Track E（API 版本控制）**
```
E1
3.1 API 版本控制与废弃机制
```

**Agent 6 — Track D4-D5 + F（依赖任务）**
```
D4 → D5 → F1
2.3 健康检查 → 2.4 Grafana → 4.3 生产加固
```

## 风险与缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| Track A 的 A1 变更影响 A2/A3 | 串行执行，低风险 | A1 完成后再启动 A2 |
| Track B 中 1.6 CI 扫描依赖 ruff 配置 | B4 可能需等 C3 | B4 先用默认配置，C3 完成后更新 |
| Track D 依赖 A/B 完成 | 第二波整体延后 | 第一波尽量并行最大化 |
| 多 Agent 修改同一文件（main.py） | 合并冲突 | 每个 Agent 修改 main.py 的不同区域 |

---

## 文件修改冲突预防

| 文件 | 修改者 | 区域 |
|------|--------|------|
| `main.py` | Agent 1 (1.4 密码检查) | auth 相关路由 |
| `main.py` | Agent 2 (1.2 安全头) | 中间件注册区 |
| `main.py` | Agent 4 (2.1 Prometheus) | 新端点 + 中间件 |
| `main.py` | Agent 5 (3.1 版本控制) | 路由注册区 |
| `main.py` | Agent 6 (2.3 健康检查) | 健康端点区 |

每个 Agent 修改 `main.py` 的不同函数/区域，冲突风险可控。

## 执行摘要

| 指标 | 串行 | 并行 |
|------|------|------|
| 总工时 | 76-96h | 76-96h（不变） |
| 墙钟时间 | 76-96h | **~36-40h** |
| 并行度 | 1 | **3-6** |
| Agent 数 | 1 | **6** |
| 阶段数 | 4 | **2 波** |

**加速比：约 2x**（从 ~96h 压缩到 ~40h）
