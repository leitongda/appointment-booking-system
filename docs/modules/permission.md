# 🔐 权限管理模块需求文档

## 一、模块概述

权限管理模块基于 RBAC（基于角色的访问控制）模型，实现用户、角色、菜单权限的管理。

## 二、功能清单

### 2.1 角色管理
- 角色列表查询
- 创建/编辑角色
- 配置角色菜单权限
- 角色启用/禁用

### 2.2 管理员管理
- 管理员列表
- 创建/编辑管理员
- 分配角色
- 账号启用/禁用

### 2.3 菜单管理
- 菜单树结构
- 创建/编辑菜单
- 配置菜单权限标识
- 菜单排序

### 2.4 操作日志
- 登录日志
- 操作审计日志
- 日志查询

## 三、权限模型

### 3.1 RBAC模型
```
用户(Admin) ─N:M─ 角色(Role) ─N:M─ 菜单(Menu)
                                       │
                              ┌────────┴────────┐
                              ▼                 ▼
                          目录/菜单           按钮权限
```

### 3.2 权限控制粒度
- **菜单权限**: 控制菜单是否显示
- **操作权限**: 控制按钮是否可用（增删改查）
- **数据权限**: 控制数据范围（全部/本门店/本科室/本人）

## 四、预设角色

| 角色 | 说明 | 数据范围 |
|------|------|---------|
| 超级管理员 | 所有权限 | 全部 |
| 运营管理员 | 内容、统计 | 全部 |
| 排班管理员 | 排班相关 | 全部 |
| 前台客服 | 预约、患者 | 本门店 |
| 科室管理员 | 本科室管理 | 本科室 |

## 五、数据模型

### roles 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| name | VARCHAR | 角色名称 |
| code | VARCHAR | 角色编码(唯一) |
| description | VARCHAR | 描述 |
| status | SMALLINT | 状态 |

### menus 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| parent_id | UUID | 父菜单ID |
| name | VARCHAR | 菜单名称 |
| path | VARCHAR | 路由路径 |
| component | VARCHAR | 组件路径 |
| permission | VARCHAR | 权限标识 |
| type | SMALLINT | 类型(1目录2菜单3按钮) |
| sort_order | INT | 排序 |

### role_menus 表
| 字段 | 类型 | 说明 |
|------|------|------|
| role_id | UUID | 角色ID |
| menu_id | UUID | 菜单ID |

## 六、API接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /roles | 获取角色列表 |
| POST | /roles | 创建角色 |
| PUT | /roles/:id | 更新角色 |
| PUT | /roles/:id/menus | 配置角色菜单 |
| GET | /admins | 获取管理员列表 |
| POST | /admins | 创建管理员 |
| PUT | /admins/:id/roles | 分配角色 |
| GET | /menus | 获取菜单树 |
| GET | /logs | 获取操作日志 |
