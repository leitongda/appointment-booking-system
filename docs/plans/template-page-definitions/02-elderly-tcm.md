# 模板页面级定义：长辈友好/中医康养 (elderly-tcm)

## 模板概述

| 属性 | 值 |
|------|-----|
| code | `elderly-tcm` |
| 名称 | 长辈友好/中医康养 |
| 定位 | 低认知负担模板，大字号、大按钮、强引导 |
| 适用场景 | 中医馆、康养门诊、老年用户为主的医疗机构 |
| 主色 | `#8B6F47` (温暖棕) |
| 字号基准 | 36px (body) / 72px (display) — 比标准模板大 20% |
| 特殊约束 | forceElderMode=true, confirmBeforeAction=true |

## 2. 首页 (home → home-elderly)

### Shell: `HomeElderly`

### 布局结构

```
┌─────────────────────────┐
│      顶部状态栏           │
├─────────────────────────┤
│  快速操作 (1)             │
│  ┌─────────┬─────────┐  │
│  │  快速挂号  │  我的预约 │  │
│  │  (大图标)  │  (大图标) │  │
│  │  2列大按钮 │           │  │
│  └─────────┴─────────┘  │
├─────────────────────────┤
│  通知公告 (2)             │
│  ┌─────────────────────┐│
│  │ 📢 今日门诊安排通知    ││
│  │ 单行滚动公告          ││
│  └─────────────────────┘│
├─────────────────────────┤
│  最近看过的医生 (3)        │
│  ┌─────────────────────┐│
│  │ [头像] 张医生  心内科  ││
│  │         上次: 3/15    ││
│  │ [再挂一次]            ││
│  └─────────────────────┘│
│  最多显示 3 位             │
├─────────────────────────┤
│     (底部 TabBar)         │
└─────────────────────────┘
```

### 与标准模板的核心差异
- **无 Banner 轮播**: 老年用户容易误触轮播，改为固定大按钮
- **2 列大按钮替代 4 列小图标**: 触控面积 >= 88rpx
- **简化模块数量**: 3 个模块 vs 标准的 4 个
- **最近看过**: 引导复诊而非探索新医生

### 模块详细定义

#### Module 1: quick_action
- **类型**: 2 列大按钮
- **固定项**: 快速挂号、我的预约
- **按钮尺寸**: 宽度 ~330rpx, 高度 ~180rpx
- **视觉**: 圆角 24px，棕色渐变背景，白色图标+文字
- **交互**: 直接跳转，无需二次确认

#### Module 2: simple_notice
- **类型**: 单行滚动公告
- **数据源**: `GET /api/v1/notices?limit=3`
- **视觉**: 浅黄/米色背景，深棕文字，字号 32px
- **交互**: 点击查看详情

#### Module 3: recent_doctor
- **类型**: 大卡片列表
- **数据源**: `GET /api/v1/appointments?recent_doctors=true&limit=3`
- **显示内容**: 头像(大)、姓名、科室、上次就诊日期
- **特有按钮**: "再挂一次" → 直接进入该医生的排班页
- **空态**: "还没有看过医生，去挂号吧" + 引导按钮

### 首页文案
- 挂号按钮: **挂号** (而非"预约挂号")
- 空态: "您还没有挂过号，点这里挂号"
- 再挂按钮: "再挂一次"

### 与标准模板的核心差异

### 视觉处理
- 格子尺寸: ~330rpx x 200rpx
- 图标大小: 80rpx (标准模板的 2 倍)
- 文字大小: 36px (加粗)
- 圆角: 24px
- 颜色: 暖棕色背景 + 白色文字

### 与标准模板的核心差异

- **大条目高度**: 每项 >= 100rpx (标准 88rpx)
- **去掉低频项**: 收藏、反馈、消息中心降级或隐藏
- **菜单重新排序**: 按使用频率排列

2. 扫码签到 (到院必用)
3. 联系客服 (求助通道)
4. 就诊人管理
5. 设置

## 8. 固定页面

| 页面 | 路径 | 老年模板适配 |
|------|------|-------------|
| 预约确认 | `/packageBooking/pages/booking/index` | 字号放大 20%，按钮加大 |
| 预约结果 | `/packageBooking/pages/booking/result` | 成功提示加大加粗 |
| 签到扫码 | `/packageBooking/pages/checkin/scan` | 扫码区域加大 |
| 签到选择 | `/packageBooking/pages/checkin/select` | 列表项加大 |

> 注意: 固定页面虽然"结构不变"，但通过 forceElderMode=true 触发全局字号/间距放大。

## 9. 视觉 Token 汇总

| Token | 值 | 对比标准模板 |
|-------|-----|-------------|
| primary | `#8B6F47` | 暖棕 vs 蓝 |
| primarySoft | `#F5EDE0` | 米色 vs 浅蓝 |
| accent | `#6B5235` | 深棕 |
| bodyFontSize | 36px | +20% |
| displayFontSize | 72px | +20% |
| radiusMedium | 24px | 更圆 |
| radiusLarge | 32px | 更圆 |
| spacingMultiplier | 1.5 | 1.5x 间距 |
| iconStyle | bold | 加粗线条 |
| tabBarIcon | filled | 实心 |
| decoration | traditional | 传统中式装饰元素 |

## 10. 文案语气

| 场景 | 标准模板 | 老年模板 |
|------|---------|---------|
| 预约按钮 | 预约挂号 | 挂号 |
| Tab 名称 | 预约 | 挂号 |
| 预约成功 | 请于就诊当天携带有效身份证件到院 | 请在看病当天带着身份证来医院 |
| 空预约 | 暂无预约记录 | 您还没有挂过号，点这里挂号 |
| 引导语 | - | 选一个时间，然后点下面的按钮挂号 |
| 确认弹窗 | 无 | 确定要挂这个医生的号吗？ |
| 语气 | 正式、简洁 | 口语化、亲切、引导性 |
