# 模板页面级定义：现代综合医疗 (modern-general)

## 模板概述

| 属性 | 值 |
|------|-----|
| code | `modern-general` |
| 名称 | 现代综合医疗 |
| 定位 | 通用型医院模板，面向大众用户，突出专业、清晰、可信赖 |
| 适用场景 | 综合医院、门诊部、连锁医疗机构 |
| 主色 | `#4D7CB8` (专业蓝) |
| 字号基准 | 30px (body) / 60px (display) |


### 模块详细定义

#### Module 1: banner
- **类型**: 轮播图
- **数据源**: `GET /api/v1/banners`
- **交互**: 点击跳转对应链接(小程序页面/webview)
- **视觉**: 圆角 16px，高度 280rpx，间距 24rpx
- **空态**: 不显示该模块

#### Module 2: quick_menu
- **类型**: 4列网格
- **固定项**: 预约挂号、科室分类、医生查询、更多服务
- **布局**: 图标(48rpx) + 文字，垂直排列
- **交互**: 需登录项触发 LoginPopup，其余直接跳转

#### Module 3: patient_card
- **类型**: 卡片
- **数据源**: `GET /api/v1/patients?default=true`
- **显示内容**: 姓名、性别年龄、默认标签
- **交互**: 点击进入就诊人管理 / 未登录触发登录
- **空态**: "添加就诊人" 引导卡片

#### Module 4: recommend_doctor
- **类型**: 横向卡片列表
- **数据源**: `GET /api/v1/doctors/recommended`
- **显示内容**: 头像、姓名、职称、科室、评分
- **交互**: 点击进入医生详情
- **视觉**: 圆角卡片，阴影 0 2px 8px rgba(0,0,0,0.06)

### 首页文案
- 页面标题: 无 (TabBar 页面)
- 空态提示: "暂无内容"
- 快捷菜单文案: 预约挂号、科室分类、医生查询、更多服务

## 3. 科室页 (department → sidebar)

### Shell: `DeptSidebar`

### 布局结构

```
┌─────────────────────────┐
│  搜索栏                  │
├────────┬────────────────┤
│ 内科   │  心内科          │
│ 外科●  │  消化内科        │
│ 妇科   │  神经内科        │
│ 儿科   │  内分泌科        │
│ ...    │  ...            │
│        │                 │
│ (左侧   │  (右侧子科室    │
│  一级    │   列表)         │
│  分类)  │                 │
├────────┴────────────────┤
│     (底部 TabBar)         │
└─────────────────────────┘
```

### 交互流程
1. 加载科室树 `GET /api/v1/departments/tree`
2. 左侧显示一级科室列表，默认选中第一个
3. 右侧显示选中科室的子科室
4. 点击子科室 → 进入该科室的医生列表
5. 若科室无子级 → 直接进入医生列表

### 视觉处理
- 左侧: 宽度 180rpx，选中项左侧蓝色竖条(4rpx) + 浅蓝背景
- 右侧: 子科室列表项，右箭头指示可跳转
- 单科室场景: 自动跳转医生列表，不显示科室选择页

### 模块组成
1. **医生信息头**: 头像、姓名、职称、科室、从业年限、评分、关注按钮
2. **擅长领域**: 文本展示，可展开/收起
3. **排班日历**: 横向日期选择器，显示有号日期
4. **号源列表**: 上午/下午分段，每时段显示剩余号源
5. **底部操作栏**: "立即预约" 固定底部按钮

### 数据源
- 医生信息: `GET /api/v1/doctors/{id}`
- 排班: `GET /api/v1/doctors/{id}/schedules?date={date}`
- 关注: `POST /api/v1/doctors/{id}/favorite`

### 时段状态
- 可约: 蓝色文字 + "可约" 标签
- 约满: 灰色文字 + "约满" 标签
- 即将放号: 橙色 + 倒计时

## 9. 视觉 Token 汇总

| Token | 值 | 用途 |
|-------|-----|------|
| primary | `#4D7CB8` | 主色调，按钮、标签、链接 |
| primarySoft | `#EAF1F8` | 浅蓝背景 |
| accent | `#385E92` | 强调色，标题、重要信息 |
| radiusMedium | 16px | 卡片圆角 |
| radiusLarge | 24px | 大卡片圆角 |
| spacingMultiplier | 1.0 | 间距倍率 |
| iconStyle | outlined | 线性图标 |
| tabBarIcon | filled | TabBar 实心图标 |
| decoration | none | 无额外装饰 |
