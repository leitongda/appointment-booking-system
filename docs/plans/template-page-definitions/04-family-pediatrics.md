# 模板页面级定义：亲子儿科 (family-pediatrics)

## 模板概述

| 属性 | 值 |
|------|-----|
| code | `family-pediatrics` |
| 名称 | 亲子儿科 |
| 定位 | 家庭场景模板，突出就诊人切换和儿童高频服务 |
| 适用场景 | 儿童医院、儿科门诊、家庭健康中心 |
| 主色 | `#5B9BD5` (友好蓝) |
| 强调色 | `#F5A623` (活泼橙) |
| 字号基准 | 30px (body) / 64px (display) |

### 与标准模板的核心差异
- **家庭成员切换器**: 独有模块，首页顶部即展示可切换的儿童头像
- **6 格快捷菜单**: 3x2 布局，更多入口(含疫苗、儿保等儿科特有项)
- **彩色图标背景**: 每个快捷菜单项有不同的彩色圆形背景(粉/薄荷/黄/蓝)
- **常见服务模块**: 儿科高频病症快速入口

### 模块详细定义

#### Module 1: family_switcher
- **类型**: 横向头像选择器
- **数据源**: `GET /api/v1/patients`
- **显示内容**: 每位就诊人的头像 + 昵称
- **视觉**: 选中项蓝色边框 + 放大效果，末尾 "+" 添加按钮
- **交互**: 切换就诊人 → 首页部分内容联动更新(如推荐医生关联)
- **空态**: "添加宝宝" 引导卡片

#### Module 2: banner
- **类型**: 轮播图 (同标准)
- **视觉**: 圆角 20px (比标准更圆)

#### Module 3: quick_menu
- **类型**: 3x2 网格
- **固定项**: 预约挂号、儿童保健、健康体检、疫苗接种、复诊预约、急诊通道
- **视觉**: 每项彩色圆形背景(80rpx) + 白色图标
  - 挂号: `#5B9BD5` (蓝)
  - 儿保: `#7BC67E` (绿)
  - 体检: `#F5A623` (橙)
  - 疫苗: `#E87398` (粉)
  - 复诊: `#67C5CF` (薄荷)
  - 急诊: `#E8734A` (红)

#### Module 4: common_service
- **类型**: 3 列卡片
- **数据源**: 模板内置儿童常见服务
- **显示内容**: 服务图标 + 名称 + 简短描述
- **视觉**: 圆角卡片，浅色背景

#### Module 5: recommend_doctor
- **类型**: 列表卡片 (同标准但增加擅长领域)
- **数据源**: `GET /api/v1/doctors/recommended`
- **显示内容**: 头像、姓名、职称、科室、擅长摘要

## 3. 科室页 (department → dept-colorful)

### Shell: `DeptColorful`

### 布局结构

```
┌─────────────────────────┐
│  ← 选择科室              │
├─────────────────────────┤
│  ┌────┐ ┌────┐ ┌────┐  │
│  │儿科 │ │内科 │ │外科 │  │
│  │(蓝) │ │(绿) │ │(橙) │  │
│  ├────┤ ├────┤ ├────┤  │
│  │口腔 │ │眼科 │ │耳鼻 │  │
│  │(粉) │ │(薄荷│ │(黄) │  │

│  3列彩色大格子            │
│  每个科室独立背景色        │
├─────────────────────────┤
│     (底部 TabBar)         │
└─────────────────────────┘
```

### 与标准模板的核心差异
- **3 列彩色格子**: 标准是 2 列分栏，亲子模板用 3 列多彩格子
- **每个科室不同颜色**: 对应图标色系
- **圆角更大**: 20px
- **可放图标**: 格子内放儿童友好插图/图标

## 9. 视觉 Token 汇总

| Token | 值 | 对比标准模板 |
|-------|-----|-------------|
| primary | `#5B9BD5` | 友好蓝 |
| primarySoft | `#EDF4FB` | 浅蓝 |
| accent | `#F5A623` | 活泼橙 (独有色) |
| bodyFontSize | 30px | 相同 |
| displayFontSize | 64px | 稍大 |
| radiusMedium | 20px | 更圆 |
| radiusLarge | 28px | 更圆 |
| spacingMultiplier | 1.05 | 稍宽松 |
| iconStyle | filled | 实心(更活泼) |
| tabBarIcon | filled | 实心 |
| decoration | playful | 活泼装饰元素 |

### 独有装饰色

| 色名 | 值 | 用途 |
|------|-----|------|
| fun1 | `#E87398` | 粉色 - 疫苗/女宝宝 |
| fun2 | `#7BC67E` | 薄荷绿 - 保健/体检 |
| fun3 | `#F5A623` | 明黄 - 急诊/注意 |
