# 模板页面级定义：高端专科门诊 (premium-specialty)

## 模板概述

| 属性 | 值 |
|------|-----|
| code | `premium-specialty` |
| 名称 | 高端专科门诊 |
| 定位 | 品牌驱动型专科模板，突出医生、服务和品质感 |
| 适用场景 | 口腔诊所、医美机构、私立专科、会员制门诊 |
| 主色 | `#8B7355` (典雅棕) |
| 字号基准 | 28px (body) / 56px (display) — 比标准略小，更精致 |
| TabBar | **4 Tab** (首页/专家/预约/我的) — 唯一使用 4 Tab 的模板 |

---

### 与标准模板的核心差异
- **品牌 Banner 更大更沉浸**: 360rpx 高度 + 底部渐变 + Slogan
- **明星专家模块前置**: 替代就诊人卡片，品牌优先
- **特色服务模块**: 展示机构核心服务项目
- **品牌故事**: 独有模块，传递机构理念和信任感
- **更多模块数**: 5 个 vs 标准的 4 个

### 模块详细定义

#### Module 1: banner
- **类型**: 品牌展示型 Banner
- **数据源**: `GET /api/v1/banners`
- **视觉**: 全宽、大圆角(16px)、底部渐变遮罩 `linear-gradient(transparent, rgba(0,0,0,0.4))`
- **文案**: Slogan 叠加在图片上

#### Module 2: featured_doctor
- **类型**: 大卡片列表
- **数据源**: `GET /api/v1/doctors?featured=true&limit=3`
- **显示内容**: 大头像(100rpx)、姓名、头衔(院长/主任)、专长标签、简介
- **视觉**: 卡片间用细分隔线，无大间距，紧凑精致
- **交互**: "查看详情" → 医生详情

#### Module 3: featured_service
- **类型**: 3 列精致卡片
- **数据源**: 模板内置 + 后端可配置
- **显示内容**: 服务图标 + 名称 + 简短描述
- **视觉**: 浅金/米色背景，细腻阴影

#### Module 4: quick_menu
- **类型**: 4 列网格
- **固定项**: 预约咨询、在线咨询、特色项目、关于我们

#### Module 5: brand_story
- **类型**: 内容卡片
- **数据源**: 模板内置品牌文案
- **视觉**: 大留白，细体文字
- **交互**: "了解更多" → webview 品牌页

- **更精致**: 细分隔线、大留白、小圆角

## 9. 视觉 Token 汇总

| Token | 值 | 对比标准模板 |
|-------|-----|-------------|
| primary | `#8B7355` | 典雅棕 vs 蓝 |
| primarySoft | `#F6F0E3` | 米金 vs 浅蓝 |
| accent | `#6B5740` | 深棕 |
| bodyFontSize | 28px | -7% (更精致) |
| displayFontSize | 56px | -7% |
| radiusMedium | 12px | 更小更利落 |
| radiusLarge | 16px | 更小 |
| spacingMultiplier | 1.1 | 稍宽松 |
| iconStyle | thin | 细线条 |
| tabBarIcon | outlined | 线性 |
| decoration | minimal | 极简 |
