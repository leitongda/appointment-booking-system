# 模板页面级定义：女性健康 (womens-health)

## 模板概述

| 属性 | 值 |
|------|-----|
| code | `womens-health` |
| 名称 | 女性健康 |
| 定位 | 连续服务型模板，强调安心、细致、陪伴 |
| 适用场景 | 妇科医院、产康中心、女性体检中心、专科诊所 |
| 主色 | `#C4908D` (柔玫瑰) |
| 字号基准 | 30px (body) / 60px (display) |

### 与标准模板的核心差异
- **顶部问候语**: 独有，"亲爱的，今天感觉怎么样？"
- **健康服务模块**: 替代通用快捷入口，聚焦女性健康领域
- **健康提醒模块**: 独有，显示检查/复诊提醒，体现"持续陪伴"
- **柔和视觉**: 更大的圆角(20px/28px)，柔和配色

### 模块详细定义

#### Module 1: banner
- **类型**: 柔和渐变 Banner
- **视觉**: 圆角 20px，渐变背景 `linear-gradient(135deg, #FBF0F0, #F5E0DE)`
- **文案**: 健康关怀主题

#### Module 2: health_service
- **类型**: 3 列柔和卡片
- **数据源**: 模板内置 + 后端可配置
- **固定项**: 妇科检查、产康恢复、健康体检、不孕不育、微创手术、私密养护
- **视觉**: 每项浅玫瑰/粉色系背景，圆角 20px
- **交互**: 点击进入对应科室或服务详情

#### Module 3: quick_menu
- **类型**: 4 列网格
- **固定项**: 预约挂号、在线咨询、检查记录、健康提醒
- **视觉**: 细线条图标，玫瑰色系

#### Module 4: health_reminder
- **类型**: 提醒卡片
- **数据源**: `GET /api/v1/health-reminders`
- **显示内容**: 下次检查/复诊日期、上次检查日期、提醒内容
- **视觉**: 暖色背景 + 浅色边框，柔和阴影
- **交互**: "立即预约" → 关联科室医生列表
- **空态**: "暂无提醒，祝您健康"

#### Module 5: recommend_doctor
- **类型**: 列表卡片 (同标准)
- **视觉**: 卡片边框 `1px solid #F0D5D3`，圆角 20px
